# Classification of Glass Products — приложение для классификации типов стекла на основе физико-химических свойств. 
Скачайте файлы данного репозитория.
Приложение имеет две реализации: Desktop приложение и ВК-бот.
Файлы для каждой реализации следует рассматривать как отдельное приложение.
## Данные
Датасет в формате CSV или txt с целевым столбцом Type и произвольным числом признаков (ОБЯЗАТЕЛЬНО: признаки должны быть числового типа)
## Версия Python

## Desktop
### Как запустить:
- Установите зависимости: pip install -r requirements.txt.
- Запускайте python main.py.
### Возможности приложения:
#### Вкладка «Создание модели» 
- Изменить — выбрать файл данных 
- Предпросмотр — первые 5 строк таблицы отображаются автоматически 
- Выбор модели и её гиперпараметров 
- Создать модель — обучение и сохранение 
#### Вкладка «Визуализация и анализ» 
- Загрузка обученной модели из файла .pkl 
- Типы графиков: коэффициенты, матрица ошибок, ROC-кривые, метрики 
- Метрики выводятся по очереди: precision, recall, f1 
#### Вкладка «Предсказания» 
- Введите значения признаков в таблицу
- Нажмите «Предсказать Type» — модель вернёт предсказанный класс и вероятности 
- Ниже отображаются метрики модели (precision, recall, f1, accuracy) 
#### Журнал действий 
- Внизу окна — сворачиваемая панель со всеми действиями. 
#### Горячие клавиши 
- F1 — открыть справку 
- F2 — сбросить параметры модели к значениям по умолчанию 
- F3 — сохранить журнал действий в JSON-файл
## ВК-бот
### Как запустить:
- Установите зависимости: pip install -r requirements.txt.
- Создайте файл .env (скопируйте .env.example в .env).
- Вставьте свой токен в .env вместо заглушки.
- Запускайте: python main.py.
### Возможности бота:
- Обработка пользовательских файлов (в формате сообщения в чате)
- Построение OLAP по выбранным измерениям
- Настройка гиперпараметров модели
-  Обучение модели (логистическая регрессия, knn, дерево решений)
-  Загрузка моделей из формата .pkl
-  Предсказание целевой переменной по введенной строке данных
-  Визуализация — матрица ошибок, ROC, коэффициенты регрессии
-  Метрики — precision / recall / F1
-  Показ журнала сессии
